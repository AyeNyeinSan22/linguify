# User Interview — Linguify

- **Who:** Liam (English teacher, friend)
- **When:** July 2026
- **How:** Feedback form

## What they do today (without your project)

Liam uses a mix of Duolingo for daily practice and YouTube for listening comprehension. He occasionally uses grammar reference websites when preparing lesson plans. None of his tools generate personalised flashcards from his own mistakes, and none offer real-world conversation role-play.

## What they liked

- "The conversation scenarios feel practical and are useful for everyday situations like restaurants, hotels, and transportation."
- "The AI Coach gives detailed feedback that helped me understand my grammar mistakes."
- "The flashcards are useful because they are created from mistakes I actually made during practice."
- "The dashboard makes it easy to see my learning progress and keeps me motivated."
- "The application looks modern and works smoothly."

## What confused them / what's missing

- "At first, I wasn't sure which feature I should start with because there are several learning modes."
- "The CEFR level filter didn't seem to change the available scenarios, so I wasn't sure whether it was working correctly."
- "The flashcard ratings (Forgot, Hard, Good, Easy) could use a short explanation for first-time users."
- No user accounts — progress can't sync across devices.
- Speaking practice lacks detailed pronunciation feedback.
- No way to quickly resume the last session from the home page.
- Mobile layout feels cramped on smaller screens.

## What would make them actually use it

- "A recommended learning path for beginners so I know what to do first."
- "User accounts so I can pick up where I left off on any device."
- "More detailed pronunciation feedback in the speaking practice."
- "A 'Continue Learning' button to jump back into my last session."
- "Better mobile layout — it's uncomfortable to use on a small phone."

## What they'd pay / recommend

- Would recommend to other English teachers and intermediate learners.
- Sees the AI conversation practice and personalised flashcards as the strongest differentiators vs. existing apps.

## What I'll change (next steps)

- [ ] Fix CEFR filter on home page — it currently only slices 4 items instead of filtering by level
- [ ] Add tooltip explaining SM-2 flashcard ratings (Forgot / Hard / Good / Easy)
- [ ] Add a recommended learning path or "Quick Start" guide for new users
- [ ] Add "Continue Learning" section that resumes the most recent session
- [ ] Audit mobile responsiveness — test all pages at 375px viewport
- [ ] Investigate auth / cloud sync (blocker for real adoption)
